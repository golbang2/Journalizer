# Journalizer Streamlit prototype

Next.js 구현 전에 기능 흐름을 확인하는 **단일 사용자 로컬 프로토타입**입니다.
실제 OCR/API/세무 판단 없이 가상 샘플로 동작합니다. 직접 업로드한 파일은 수동 입력합니다.

## 실행 (저장소 루트)

```powershell
python -m pip install -r streamlit_prototype/requirements.txt
python -m streamlit run streamlit_prototype/app.py --server.address 127.0.0.1
```

브라우저에서 http://localhost:8501 을 엽니다.

## 시연

1. **영수증함 → 정담 식당 → 열기**: 사용 목적 선택 후 `입력값 저장 · 분개 다시 추천`.
2. 분개 금액·계정과목 편집 → 검토 체크 → 확정.
3. **분개장**: 확정 결과 확인 → CSV 다운로드.
4. 원본으로 돌아가 확정 취소 → 이력 확인.
5. **한빛 서점**: 원본 33,000원과 잘못 추출된 38,000원 비교 → 수정 → 저장.
6. **오피스 문구**: 승인번호·날짜·금액 기반 중복 경고 확인.
7. **취소/분할 샘플**: 역분개와 복수 비용 계정 확인.
8. 내 파일 업로드: 이미지/PDF 등록 → 원본 확인 → 거래처·금액 입력 → 초안 생성.

## 저장 및 제한

- `.local/records.json`에 목록·편집·확정 이력 저장. 새로고침/재실행 후 복원.
- `.local/uploads/`에 업로드 원본 저장. 두 경로 모두 Git 제외.
- 초기화는 목록과 이력만 교체하며 업로드 파일은 삭제하지 않습니다.
- 다중 사용자·동시 편집용 저장 구조가 아닙니다.
- 필드 폼의 변경은 저장 버튼을 눌러야 반영됩니다. 재추천은 수동 분개를 교체합니다.
- 영수증 금액은 원화 정수, 공급가액+부가세 구조로 한정합니다.
- PDF 뷰어가 지원되지 않는 브라우저는 원본 다운로드를 사용합니다.
- 실제 OCR 좌표 기반 강조 대신 가상 영수증 항목 강조를 제공합니다.
- 계정과목표는 조회 전용입니다. 샘플 분개 규칙은 제품 동작 시연용입니다.
